Python ve NumPy Temelleri

Bu proje, Dokuz Eylül Üniversitesi Ekonometri Bölümü İstatistiksel Programlama dersi kapsamında hazırladığım Python ve NumPy uygulamalarını içermektedir.

Kullanılan Teknolojiler

* Python
* NumPy

Proje İçeriği

* NumPy dizileri oluşturma
* Dizilerin boyutlarını, eleman sayılarını ve veri tiplerini inceleme
* Toplam, ortalama, minimum ve maksimum değer hesaplama
* Tek boyutlu dizileri iki boyutlu matrislere dönüştürme
* Matrislerin satır ve sütun sayılarını belirleme

Projenin Amacı

Python programlama dilini kullanarak temel sayısal veri işleme ve matris işlemleri konusunda uygulamalı deneyim kazanmak.
